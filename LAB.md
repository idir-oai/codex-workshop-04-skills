# Lab 04 - Skills

## Goal

Create a narrowly triggered skill and prove both a positive and negative trigger.

## Synthetic scenario

This public repository is a workshop sandbox. It contains no customer, employee, credential, confidential, or production data.

## Exercise

1. Define one repeatable synthetic workflow.
2. Create the smallest useful SKILL.md.
3. Test a request that should trigger it.
4. Test a similar request that must not trigger it.

## Safety

Use synthetic data only. Do not add secrets, personal data, production credentials, internal URLs, customer names, or proprietary source code. Do not deploy from this repository.
